## 🚀 Sobre el Proyecto

**Vanty** es una solución de software como servicio (SaaS) diseñada para optimizar y automatizar los procesos operativos, administrativos y clínicos en centros de terapia y atención especializada. 

La plataforma centraliza la gestión de pacientes, historiales clínicos, control de pagos y la activación de servicios bajo una arquitectura web moderna, rápida y segura.

## ✨ Características Principales

* 🏢 **Gestión de Centros:** Administración multi-cliente para el control de sedes y perfiles clínicos.
* 📊 **Panel de Administración (Admin Dashboard):** Métricas clave en tiempo real sobre centros activos, ingresos y estados de cuenta.
* 📱 **Landing Page Comercial:** Interfaz pública optimizada para la conversión y captación de clientes con integración directa a canales de contacto y WhatsApp.

## 🛠️ Stack Tecnológico

* **Frontend & Framework:** Next.js (App Router), React, TypeScript.
* **Estilos:** Tailwind CSS, Lucide Icons.
* **Backend & Base de Datos:** Supabase (PostgreSQL, Row Level Security, Auth).
* **Despliegue:** Vercel.
